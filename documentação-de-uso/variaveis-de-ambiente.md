# Variáveis de ambiente — configuração do servidor

Lidas pelo [docker-entrypoint.sh](../docker-entrypoint.sh), que monta a linha de comando do `telegram-bot-api` a partir delas. Ver flags originais em [telegram-bot-api.cpp](../telegram-bot-api/telegram-bot-api.cpp).

| Env                                 | Flag CLI equivalente          | Obrigatório | Valor                                | Efeito                                                                                                                                                   |
| ----------------------------------- | ----------------------------- | ----------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TELEGRAM_API_ID`                   | `--api-id`                    | Sim         | Integer                              | ID do app, gerado em https://my.telegram.org                                                                                                             |
| `TELEGRAM_API_HASH`                 | `--api-hash`                  | Sim         | String                               | Hash do app, gerado em https://my.telegram.org                                                                                                           |
| `TELEGRAM_LOCAL`                    | `--local`                     | Não         | Qualquer valor não-vazio liga        | Remove limite de tamanho de arquivo (20/50MB → 2000MB). `getFile` passa a retornar `file_path` absoluto do disco em vez de path relativo pra montar link |
| `TELEGRAM_RELATIVE`                 | `--relative`                  | Não         | Qualquer valor não-vazio liga        | Só tem efeito com `LOCAL=1`: força `file_path` relativo em vez de absoluto (não usado neste projeto — ver seção abaixo)                                  |
| `TELEGRAM_STAT`                     | `--http-stat-port=8082`       | Não         | Qualquer valor liga, porta fixa 8082 | Liga endpoint `/stats` (monitoramento interno)                                                                                                           |
| `TELEGRAM_STAT_HIDE_SENSIBLE_DATA`  | `--stats-hide-sensible-data`  | Não         | Liga/desliga                         | Esconde token do bot e URL do webhook na saída do `/stats`                                                                                               |
| `TELEGRAM_VERBOSITY`                | `--verbosity=N`               | Não         | Integer ≥0 (0=fatal ... 5+=debug)    | Nível de log                                                                                                                                             |
| `TELEGRAM_FILTER`                   | `--filter=rem/mod`            | Não         | String `"resto/modulo"`              | Sharding: só serve bots onde `bot_id % modulo == resto`                                                                                                  |
| `TELEGRAM_MAX_WEBHOOK_CONNECTIONS`  | `--max-webhook-connections=N` | Não         | Integer                              | Conexões simultâneas padrão por webhook de bot                                                                                                           |
| `TELEGRAM_MAX_CONNECTIONS`          | `--max-connections=N`         | Não         | Integer                              | Máx file descriptors abertos pelo processo                                                                                                               |
| `TELEGRAM_PROXY`                    | `--proxy=http://host:port`    | Não         | URL                                  | Proxy HTTP de saída pras requisições de webhook                                                                                                          |
| `TELEGRAM_NO_FILE_LIMIT`            | `--no-file-limit`             | Não         | Liga/desliga                         | Remove limite de tamanho de arquivo sem precisar de `LOCAL`                                                                                              |
| `TELEGRAM_ALLOW_USERS`              | `--allow-users`               | Não         | Liga/desliga                         | Permite conta de usuário (userbot), não só bot, autenticar na API                                                                                        |
| `TELEGRAM_ALLOW_USERS_REGISTRATION` | `--allow-users-registration`  | Não         | Liga/desliga                         | Permite registrar conta de usuário nova via API                                                                                                          |
| `TELEGRAM_INSECURE`                 | `--insecure`                  | Não         | Liga/desliga                         | Permite enviar webhook via HTTP puro (sem TLS)                                                                                                           |
| `TELEGRAM_MAX_BATCH`                | `--max-batch-operations=N`    | Não         | Integer                              | Máx operações em lote (batch)                                                                                                                            |
| `TELEGRAM_FILE_EXPIRATION_TIME`     | `--file-expiration-time=N`    | Não         | Integer (segundos)                   | Expira arquivo baixado após N seg sem uso                                                                                                                |
| `TELEGRAM_HTTP_IDLE_TIMEOUT`        | `--http-idle-timeout=N`       | Não         | Integer (segundos)                   | Timeout de conexão HTTP ociosa                                                                                                                           |
| `TELEGRAM_LOGS`                     | `--log=path`                  | Não         | Path                                 | Destino do log (default `/proc/1/fd/1`, stdout do container)                                                                                             |
